# 1. 簡報建置器介紹：HTML-Deck-builder
> 透過 Spec-Driven 與自動化腳本，將 Markdown 講稿快速編譯為 16:9 的精美互動簡報網頁。

## 專案核心特色

### 🎨 現代雜誌風格 (Modern Magazine)
- 視覺以「乾淨、編輯感、專業、文字與圖像並重」為品牌導向。
- 使用高雅色調：白色卡片、深灰色文字與亮紅色強調整體質感。
- 專門適合商業簡報、政策宣導、技術培訓與法規說明等正式場合。

### 📦 零依賴建置工具
- 採用 Node.js 原生 API 開發，不需要安裝複雜的前端框架或依賴套件。
- 提供 `build.mjs` 自動編譯器與 `dev.mjs` 本地預覽伺服器（支援存檔自動重載）。
- 單一輸出的 HTML 簡報包含所有樣式與導覽 JS，可本機直接開啟或隨意部署。

# 2. Markdown 元件：豐富的投影片 UI
> 支援多種 Markdown 語法轉換，讓 AI 在撰寫投影片內容時擁有極佳的版面彈性。

## 元件效果展示

### 💻 提示塊與終端機 (Prompt Block)
- 使用 fenced code blocks 並指定 `prompt` 語言，編譯器會自動生成漂亮的模擬控制台：

```prompt [label="編譯範例"]
node .agents/skills/deck-builder/scripts/build.mjs example
```

- 右上角可顯示工作標籤，並內建一鍵複製按鈕。

### ⏳ 深度洞察框 (Insight Box)
> **AI 改變開發流程的本質**
> 當我們使用 AI 寫程式時，人容易成為瓶頸。因此必須建立規範與文件。
>
> 寫測試情境其實不是浪費時間，而是為了讓我們能更大膽地使用 AI 做功能迭代與重構。

- 洞察框支援段落與項目列表。

### 🚀 流程步驟 (Flow Steps)
- 使用 `[flow]` 區塊，將 ordered list 自動排版為引導式的流程圖：

[flow]
1. 寫講稿 — 撰寫結構化的 content.md
2. 改設定 — 覆蓋 config.yaml 與 global.yaml
3. 執行 build — 生成 index.html 簡報網頁
[/flow]

### 🏷️ 狀態標籤 (Tags)
- 用 `[tags]` 標記，為條列項目加上特定顏色的亮眼標籤：

[tags]
- [orange] 手工排版：風格不一、耗時費力
- [purple] AI 隨機產出：排版隨機、難以控制
- [green] 本專案解法：自動化模板編譯
[/tags]

### 📝 勾選驗證清單 (Checklist)
- 透過 `- [x]` 自動產生美觀的打勾清單，非常適合呈現測試情境與檢核項目：

- [x] 表單輸入驗證：格式錯誤前端主動擋下
- [x] 響應式介面：支援電腦、平板與手機等不同螢幕尺寸
- [x] 離線使用：完全不依賴外部 CDN，無網路環境亦可開啟

# 3. 媒體影片與總結
> 簡報中可自由整合影片、YouTube 外部連結以及高對比的對比表格。

## 影像整合與成果

### 📺 影片播放展示
- 支援透過影片短代碼嵌入本地 MP4 影片或 YouTube Iframe 影片，並配上重點提示：

[youtube id="0pZri5f_tfk" title="HTML-Deck-builder 完整教學"]

- 編譯後會自動生成精緻的影片卡片，並提供一鍵跳轉 YouTube 按鈕。

### 📊 決策與比較表格 (Table)
- 支援標準 Markdown 表格，編譯成具有排序功能的比較矩陣：

| 評估維度 | 傳統 PowerPoint 簡報 | HTML-Deck-builder |
| :--- | :--- | :--- |
| 開發效率 | ⏳ 中等（需手動調整排版） | ⚡ 極快（Markdown 自動排版） |
| 版本控制 | ❌ 困難（二進位檔案無法 diff） |  極佳（純文字，Git 完美追蹤） |
| 跨平台分享| ⚠️ 需安裝 Office 軟體 | 💻 點擊即開（單一 HTML 檔案） |
